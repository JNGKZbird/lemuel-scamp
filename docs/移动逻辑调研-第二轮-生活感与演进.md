# 捣蛋鬼计划 · 移动逻辑调研（第二轮）——生活感与演进

> 调研日期：2026-10-17 ｜ 性质：设计参考，未拍板
> 用户定调：**早期只做"自己过自己"的五件套**（待机/行走/戳一戳/坐立/睡觉）；**FNF、抢鼠标等交互内容出现后再优化行为树**；**Agent 实装后两人再互相互动**。
> 本轮回答三件事：①五件套怎么做出生活感；②什么时候、怎么升级到行为树；③Agent 时代双角色互动的分层。

---

## 0. 摘要（先看这页）

- **生活感 ≠ 动画数量**。成熟桌宠的共同公式：**连续行为链＋分层权重＋节奏/环境条件＋空间化行动＋轻互动**。动画多只是加分项。
- **五件套的上限**：不能靠新动作制造变化，只能靠**节奏、目标点、低频事件、时段信号**。这正好符合"早期不扩内容"的定调。
- **架构演进**：平面 FSM 现在就够；交互到来后走**混合架构**（高层模式 FSM／例程行为树／候选选择加权或 Utility）；Agent 时代再加**LLM 意图层**——LLM 只出意图，不碰骨骼。
- **现在不要做**：需求条/属性系统、行为树、LLM、时段逻辑——全部留到对应的阶段。
- **为演进该做的准备**（现在就能做、零成本）：状态表数据化、意图抽象、事件入口与优先级、调度与渲染解耦。

## 1. 五件套怎么做出生活感

### 1.1 别人家的做法（案例）

| 案例 | 关键做法 | 可借什么 |
|---|---|---|
| **dsh-pet**（DSH 插件） | 不做"循环待机"：25 个约 10 秒动画，播完按概率切下一个，形成"过日子"的行为链。权重示例：待机呼吸 30% / 张望 10% / 随机动作 40% / 屏幕漫游 20% | **行为链＋分层权重**的核心思想；我们动画少，靠节奏复刻 |
| **LUMI 桌面宠物** | 64 种行为、122 张画面；歪头、哼歌、蹦跳、坐下东张西望、自言自语 | 微动作与空间移动叠加，比单加动画更有效 |
| **桌喵** | 发呆、闲逛、找地方睡、上爬架，眼神追随鼠标 | "找地方睡"＝空间化的睡眠，不只是原地 |
| **奶茶鼠桌宠** | 日常/休息/吃饭/学习/工作/低概率事件按权重切换 | **低频彩蛋层**：用低概率事件制造惊喜 |
| **Tablepet / 虚拟桌宠模拟器** | 读系统时间、鼠标活跃度；长时间静止后自动休眠；参数化计算间隔/互动周期 | 时段与环境信号驱动作息；参数可调 |
| **The Sims** | 需求（饥饿/精力等）衰减→阈值触发行动→"智能物件"提供动作→按情绪/效用选择 | 需求驱动在复杂系统里有效；**对我们偏重，早期不采纳** |
| **Tamagotchi** | 极简照料—情绪回路，靠交互维持状态 | 轻焦虑、低惩罚的养育感；"不死不病不惩罚"的轻压力哲学（鲸鱼娘 GDD 同调） |

### 1.2 只有五件套时，生活感的来源

1. **行为链，而不是"待机循环"**：每个动作自然结束→按权重选下一个，永远有下一件事在酝酿。
2. **分层权重**：基础待机（Relax）／空间漫游（Move）／低频坐下（Sit）／低频睡觉（Sleep）／交互反应（Interact）。我们只能在这五类里组合。
3. **节奏参数**：待机时长、走路概率、空间目标点距离、坐/睡概率——这就是行为档位（安静/标准/活跃）的意义。
4. **空间化**：散步要有目标点（去屏幕某个位置），而不是"边到边"；坐/睡也可以发生在"走到某处之后"。
5. **低频事件**：在五件套内用低概率改变顺序（例如"先走到角落再睡"），制造"今天有点不一样"的感觉。
6. **轻互动**：戳一戳、拖拽（已有）；不打扰、随时可打断。
7. **（可选、需拍板）时段/闲置信号**：夜间偏睡、长时间无人动偏静。**这是游戏外的新逻辑**，按定调应晚于五件套核心，建议列为"可选增强"。

**结论**：五件套并不会让生活感"注定贫乏"；贫乏的是节奏。先把参数表和档位做好，再谈扩展。

## 2. 什么时候、怎么升级行为架构

### 2.1 三种架构对比

| 架构 | 扩展性 | 优点 | 局限 | 适用 |
|---|---|---|---|---|
| FSM / HFSM | 低–中 | 简单、可预测、便宜、易调 | 状态一多转移爆炸（约 8–10 个状态开始难维护） | 高层模式、小状态集 |
| 行为树（BT） | 高 | 模块化、可复用子树、顺序/回退/中断好写 | 树大了难平衡、隐藏状态、偏重 | 复杂例程：通勤→工作→吃饭，失败回退 |
| Utility AI | 最高 | 连续权衡需求/风险/距离/性格，涌现性强 | 归一化/曲线/权重难调，易抖动，成本高 | "下一件事选什么"的竞争选择 |

**推荐演进路线**（与定调一致）：
- **现在**：平面 FSM＋加权调度（已实现）。五件套的上下文互斥、状态少，够用且最好调。
- **交互到来后**（FNF、抢鼠标、召唤）：升级为**混合架构**——
  - 高层模式用 FSM/HFSM：生活 / 对战 / 抢鼠标 / 被拖 / 隐藏；
  - 例程用行为树：`Sequence(走过去 → 面对 → 触发对战 → 回退)`，带 fallback 与中断；
  - 候选选择用现有权重或轻量 Utility（选"下一件日常事"）。
- **Agent 时代**：在混合架构之上加 LLM 意图层（见 §3）。

### 2.2 迁移成本控制（现在就该做的准备）
- **状态表数据化**：状态 ID、动画、进入/退出、允许转移、优先级、最小停留——已按此组织。
- **意图（Intent）抽象**：调度器输出"意图"（去某点/播放某动作/等待 N 秒），而不是直接改状态机内部字段。以后换 BT 只换调度器，动画/运动层不动。
- **事件入口**：拖拽/戳一戳已经是"外部事件→优先级接管"的样本；召唤/抢鼠标将来接同一入口。
- **调度与渲染解耦**：渲染层只认当前动画名与一次性/循环标志（已具备）。
- **何时必须升级**：当状态数超过 8–10 个、或出现多步条件例程、或需要"失败回退/并行分支"时——也就是 FNF 与抢鼠标加入的时候。

## 3. Agent 时代的双角色互动

### 3.1 Generative Agents 式循环（可参考的骨架）
`人格＋私人目标 → 日计划（时间/地点/活动）→ 情境行动/对话 → 记忆与反思 → 关系更新 → 修计划`
- 日计划是分层的：日级块→小时级子计划→即时动作序列。
- 记忆：短期（最近 50–100 条）＋长期压缩摘要；按情绪权重与重复强化检索。
- 双角色：**社交图**记录亲密度、信任、历史与角色；对话是否发起由 LLM 依据记忆与情境决定。

### 3.2 对我们的分层建议
- **LLM 只出意图包**（去哪、做什么、说什么），由本地行为层验证与执行；验证失败回退到小调度器。**绝不让 LLM 直接驱动骨骼或动画名。**
- 双角色各自有 persona/记忆；共享世界时钟与关系状态；互动编排由协调层统一。
- 角色卡建议：公开身份／私人目标／固有性格／已学技能／当前心事／生活节奏——私人目标驱动长期行为，避免"只会寒暄"。
- **风险**：长对话容易同质化（Willowbrook 的教训：礼貌但雷同、状态连贯性脆弱）。对策：共享目标/冲突、编写剧情节拍（内容骨架仍由我们写），LLM 只负责时刻级的"生活纹理"。
- **成本**：记忆检索与摘要要稳定、可解释；对话历史要裁剪，防止漂移与烧词元（与本项目"词元经济"口径一致）。

### 3.3 早期不接 LLM，但把接口留好
- 调度器的"意图"接口就是将来的 LLM 接口；现在把行为写成"意图执行器"，将来接 Agent 只是多一个意图来源。
- 双角色互动建议等到 Agent 实装后再做（按定调）。

## 4. 落地建议（按定调）

### 现在（第二轮落地范围）
- 五件套行为链＋权重档位（已实现：idle 3–8s，走 45%，坐 12%，睡 5%）。
- 随机目标点散步、坐/睡一次性/定时、打断恢复。
- **不新增**：需求条、时段逻辑、LLM、行为树。

### 可选轻量增强（拍板后做）
- **时段/闲置轻逻辑**：夜间偏睡、久无操作偏静（游戏外新逻辑，按定调可延后）。
- **低频彩蛋**：五件套内的顺序变化（"走到角落再睡"），不新增动画。
- **行为档位设置界面**：安静/标准/活跃三档，双角色独立。

### 中期（FNF / 抢鼠标上线时）
- 混合架构：高层模式 FSM＋例程行为树＋加权/Utility 选择；把五件套扩成动作库；交互状态机（对战、抢鼠标、被拖、隐藏）。

### 远期（Agent 实装后）
- LLM 意图层＋社交图＋记忆与反思；双角色互动由 LLM 提议、行为层执行；剧情节拍由我们编写。

## 5. 待拍板

1. 是否加入**时段/闲置驱动的轻量作息**（游戏外新逻辑；建议晚于五件套核心）。
2. 行为档位的**默认档**（安静/标准/活跃）与是否每角色独立（建议独立）。
3. FNF／抢鼠标的启动时机（它们就是行为树升级的信号）。
4. Agent 分层是否按"LLM 意图＋本地行为层"设计（建议是）。
